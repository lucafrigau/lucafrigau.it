# lucafrigau.it

`lucafrigau.it` e `www.lucafrigau.it` portano alla stessa pagina di
[lucafrigau.com](https://lucafrigau.com), il sito di Luca Frigau.

GitHub Pages serve un solo dominio per sito, quindi il `.it` ha questo
repository a parte. `index.html`, e `404.html` per ogni altro indirizzo,
mandano il visitatore all'indirizzo corrispondente su `lucafrigau.com`
(senza JavaScript, alla pagina iniziale). Il sito e la sua documentazione
sono in [lucafrigau/lucafrigau.com](https://github.com/lucafrigau/lucafrigau.com).
